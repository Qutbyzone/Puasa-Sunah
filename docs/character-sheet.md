## 2. Daftar Ekspresi dan Pose Kaka

### 2.1 Ekspresi Wajah (7 Ekspresi Standar)

---

#### 😊 Ekspresi 1: SENANG (Happy)
**Digunakan saat:** Menyambut pengguna, memulai aktivitas baru, memberikan pujian sederhana.

| Bagian | Deskripsi |
|---|---|
| **Mata** | Mata terbuka penuh, berbentuk agak menyipit (senyum mencapai mata). Specular highlight bersinar terang |

| Bagian | Deskripsi |
|---|---|

## 3. Panduan Konsistensi Karakter

### 3.1 Proporsi Wajib

| Elemen | Ukuran Relatif | Catatan |
|---|---|---|
| **Rasio kepala-tubuh** | 1 : 4,5 | Kepala lebih besar dari manusia nyata, tapi tidak lebay |
| **Lebar bahu** | = 1,5× lebar kepala | Bahu tidak terlalu lebar, masih anak-anak |
| **Panjang kaki** | = 2× tinggi kepala | Kaki proporsional, tidak terlalu panjang/pendek |
| **Panjang lengan** | = 1,5× tinggi kepala | Lengan rileks menjangkau pertengahan paha |
| **Ukuran mata** | = 1/4 lebar wajah | Mata besar khas kartun ramah |
| **Ukuran telinga** | = 1/4 tinggi kepala | Normal, tidak terlalu menonjol |

### 3.2 Panduan Warna yang Tidak Boleh Berubah

| Elemen | Hex Warna | Keterangan |
|---|---|---|
| Kulit dasar | `#C68642` | WAJIB konsisten di semua aset |
| Kulit highlight | `#D4956A` | Selalu di area yang sama |
| Kulit shadow | `#A0622E` | Selalu di area yang sama |
| Rambut | `#1A1A1A` | Hitam pekat, tidak boleh abu-abu gelap biasa |
| Rambut highlight | `#3D3D3D` | Hanya di puncak rambut |
| Iris mata | `#5D3A1A` | Coklat gelap, tidak boleh hitam |
| Kemeja | `#00897B` | Teal standar, tidak boleh variasi |
| Celana | `#8D6E63` | Coklat khaki standar |
| Tas | `#8D6E63` / `#6D4C41` | Dua ton coklat, selalu sama |
| Outline karakter | `#1A1A1A` | Hitam pekat, tebal 3px (di 1080p) |

### 3.3 Gaya Outline

| Properti Outline | Nilai |
|---|---|
| **Warna** | `#1A1A1A` (hitam pekat, bukan `#000000` murni) |
| **Ketebalan standar** | 3px pada ukuran karakter di layar 1080p |
| **Ketebalan saat karakter kecil** | 2px (skala proporsional dengan ukuran) |
| **Gaya** | Line art bersih, sudut tumpul di lengkungan pakaian |
| **Detail dalam karakter** | Outline tipis 1–1.5px untuk lipatan pakaian, fitur wajah dalam |
| **Teknik** | Cel-shading: tidak ada gradasi halus, hanya 2–3 level tonal (highlight, mid, shadow) |

### 3.4 Sudut Pandang (View Consistency)

| View | Kapan Digunakan | Catatan |
|---|---|---|
| **Full frontal** | Dialog, perkenalan, memberi selamat | Wajah lurus menghadap pengguna |
| **3/4 view kanan** | Menunjuk, menjelaskan, berjalan ke kanan | Wajah tampak ¾, telinga kiri terlihat |
| **3/4 view kiri** | Berjalan ke kiri, membawa peta | Wajah tampak ¾, telinga kanan terlihat |
| **Side profile** | Hanya untuk animasi berjalan (opsional) | Jarang, hanya jika diperlukan |

### 4.4 Catatan Penting untuk Animator/Illustrator

> [!IMPORTANT]
> Poin-poin berikut WAJIB diperhatikan oleh siapapun yang membuat aset visual Kaka.

1. **Jangan mengubah warna kulit** — gunakan hex yang tertera, termasuk highlight dan shadow.
2. **Outline SELALU hitam** `#1A1A1A` — jangan menggunakan warna outline yang berbeda untuk bagian apapun.
3. **Mata Kaka** selalu memiliki dua highlight putih `#FFFFFF` berbentuk oval kecil di kanan atas setiap mata.
4. **Blush pipi** hanya muncul pada ekspresi Senang dan Memberi Selamat — tidak pada ekspresi lain.
5. **Tas selalu terlihat** kecuali pada close-up wajah (bust shot).
6. **Topi** adalah aksesori opsional — boleh ditampilkan atau dilepas konsisten dalam satu set aset.
7. **Peta** muncul sebagai properti fisik hanya di Pose Membawa Peta — di pose lain, peta ada di dalam tas.
8. **Ekspresi Sedih** harus selalu disertai narasi/teks penyemangat — jangan tampilkan sendirian.
9. **Line weight** konsisten: outline karakter 3px, detail internal 1–1.5px.
10. **Color fills** menggunakan flat color (cel-shading) — tidak ada gradasi halus di badan karakter.
