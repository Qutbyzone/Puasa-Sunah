## 5. ASET AUDIO (NARASI, MUSIK & EFEK SUARA)

> **Catatan Teknis Lingkungan:** Generator audio AI (TTS suara anak/musik AI) tidak tersedia di lingkungan kerja. Tidak ada file tiruan yang dibuat.
> **Solusi Implementasi Tahap 3:** 
> - Efek suara (SFX) diimplementasikan secara dinamis menggunakan **Web Audio API** bawaan JavaScript (100% offline, tanpa file eksternal).
> - File narasi MP3 dan musik eksternal disiapkan slot modularnya jika pengguna mengunggah rekaman.

| Kategori | Folder Target | Metode Implementasi | Status |
|---|---|---|:---:|
| **Efek Suara (SFX)** | `assets/audio/sfx/` | Web Audio API Oscillator & Gain (Klik, Benar, Salah, Fanfare) | ✅ **Siap di Tahap 3 (Prosedural)** |
| **Musik Latar (BGM)** | `assets/audio/music/` | Web Audio Chords / Slot File MP3 Modular | 🔄 **Modular Slot** |
| **Narasi Suara Kaka** | `assets/audio/narration/` | Web Speech API Fallback / Slot Rekaman MP3 | 🔄 **Modular Slot** |
